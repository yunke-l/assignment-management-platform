# Classwork 猫头鹰主题

以卡通猫头鹰 Ollie 为主形象，配合奶油白、森林绿和暖杏色，让学习空间更亲切，同时保留教师需要的清晰结构与操作效率。

## 页面与交互

- 登录页采用读书猫头鹰、简短欢迎语和独立登录卡片。
- 作业、班级和账号页面使用统一的导航、标题、表单和状态标签。猫头鹰出现在欢迎区、空状态及提交结果中。
- 教师工作区保留桌面双栏布局、筛选、题目编辑与成绩表格，主操作使用深绿色按钮。
- 手机和平板采用单栏工作区；新建或选择作业后自动定位详情，并提供返回作业列表按钮。窄屏表单使用单列布局。
- 保留 Classwork 名称、现有界面语言与业务规则。

## 色彩与实现

| 用途           | 色值      |
| -------------- | --------- |
| 主要文字       | `#283f35` |
| 品牌与主要操作 | `#245747` |
| 次要文字       | `#617064` |
| 页面背景       | `#f8f8f2` |
| 卡片背景       | `#fffefb` |
| 欢迎区背景     | `#fbf2d9` |
| 选中状态       | `#edf3e3` |
| 键盘焦点       | `#a86a27` |

猫头鹰为项目内原创 SVG，位于 `apps/web/src/Owl.tsx`，提供读书、挥手和庆祝三个姿态；网站图标位于 `apps/web/public/favicon.svg`。使用系统字体，无新增依赖或外部图片、字体请求。

保留原生表单标签、单选控件和可见键盘焦点；装饰插图对辅助技术隐藏，登录页主插图提供文字标签。支持减少动态效果设置，手机输入框字号至少 16px。这些措施不代表完成了全面的无障碍认证。
